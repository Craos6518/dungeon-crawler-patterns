# Dungeon Crawler Académico — Patrones de Diseño en Java

Proyecto académico desarrollado en **Java 17** para demostrar la aplicación de **patrones de diseño de software** en un videojuego tipo Dungeon Crawler por turnos.

## 🚀 Inicio Rápido

```bash
# Compilar proyecto
mvn clean compile

# Ejecutar juego interactivo
mvn exec:java -Dexec.mainClass="game.InteractiveGame"

# Ejecutar demo de integración total
mvn exec:java -Dexec.mainClass="game.demo.IntegracionCompletaDemo"
```
