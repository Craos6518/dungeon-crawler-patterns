# Scripts del proyecto

Scripts operativos movidos desde la raiz para mantener el repositorio mas ordenado.

## Ejecucion

- `./scripts/play.sh`: arranque en consola
- `./scripts/play-gui.sh`: arranque GUI
- `scripts\play.bat`: arranque en Windows

## Preparacion

- `source scripts/setup-java.sh`: configura `JAVA_HOME` para Java 17
- `./scripts/verificar-config-vscode.sh`: valida entorno local de VS Code

## Empaquetado

- `./scripts/package-linux.sh`: genera paquetes Linux
- `.\scripts\package-windows.ps1`: genera artefactos Windows
