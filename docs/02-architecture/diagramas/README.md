# Galería de Diagramas de Arquitectura

Esta carpeta contiene dos formatos por diagrama:

- `*.png`: vista lista para abrir en VS Code, GitHub o cualquier visor de imágenes.
- `*.txt`: fuente editable en sintaxis PlantUML (`@startuml ... @enduml`).

## Cómo visualizar

- Si quieres ver los diagramas de inmediato, usa los PNG de esta galería.
- Si quieres editar/re-renderizar fuentes PlantUML, abre los `*.txt` con soporte PlantUML en VS Code.
