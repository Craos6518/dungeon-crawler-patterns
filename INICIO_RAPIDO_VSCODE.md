
# 🚀 Inicio Rápido - VSCode + Java 17

## 1. Abrir el proyecto
```bash
cd "/run/media/craos6518/Externo/back/Proyecto Patrones de diseño/dungeon-crawler-patterns"
code .
```

## 2. Instalar extensiones
Cuando VSCode se abra, haz clic en **"Install All"** en la notificación de extensiones recomendadas.

## 3. Recargar VSCode
`Ctrl+Shift+P` → "Reload Window" → `Enter`

## 4. Verificar configuración
Abre la terminal (`Ctrl+Shift+ñ`) y ejecuta:
```bash
./verificar-config-vscode.sh
```

## 5. ¡Listo!
- **Compilar**: `Ctrl+Shift+B`
- **Ejecutar**: `F5`
- **Tests**: Click en icono 🧪 en la barra lateral
